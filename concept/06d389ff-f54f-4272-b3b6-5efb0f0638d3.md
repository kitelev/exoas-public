# concept__Concept_genus

Аристотелев род (definitional kind) концепта — тип/суперкласс, к которому концепт относится по своей сути.

## Семантика
- Domain: concept__Concept
- Range: concept__Concept (род = сам концепт-узел → genus-цепочки walkable, CQ1 субсумпция)
- Cardinality: 0..1 (Single, maxCount=1; min=0 — НЕ forced). Кросс-классификация → расщепление концепта (Delta-3), не multi-genus.
- Полиморфна: индивид-концепт → genus как тип; род-концепт → genus как superClass.

Аддитивно (Delta-1, RFC b860de33); инстанс-заполнение = Delta-3.
