# concept__ConceptDefinitionSpec

Класс, описывающий как ВЫЧИСЛЯЕТСЯ `concept__Concept_definition` концепта из его интенсиональной структуры (genus + differentia) — Аристотелева прозрачность: объявляешь genus/differentia, определение рендерится. Аналог `exo__DisplayNameSpec`, но таргетит поле `definition` (а не заголовок).

## Свойства
- `concept__ConceptDefinitionSpec_appliesToClass` — концепт-класс, для которого композиция применяется (range concept-класс, 1).

Части spec связаны через `exo__DisplayNamePart_of` (UWI child→parent), упорядочены `exo__DisplayNamePart_order`: `exo__PrintedProperty` печатает значение свойства (1-hop → target's `exo__Asset_label`; multi-value differentia — все прилагательные через движковый array-join), `exo__PrintedLiteral` — литерал-separator.

Семантика **materialized-OR-computed** (RFC b860de33): computed где genus присутствует; stored free-text где genus нет; fail-closed (нет чистого genus-лейбла → не фабриковать). Sibling `exo__DisplayNameSpec` (presentation-declaration).
