# Visible only when the task is archived

Atomic SPARQL ASK precondition (req `f9da9867`): returns `true` only when the
target carries the archived flag `exo__Asset_archived "true"` (the bare `archived`
frontmatter key, whitelisted → `exo:Asset_archived` triple per RFC 871c1e56;
value is the literal string `"true"`).

Gates the «Un-archive» command (`59aaf685`) so it is offered **only** on an
archived task and hidden on every non-archived one. The archive flag is set
in place by the `archiveAsset` service (`ArchiveAssetService`, no file move), so
the inverse is purely the presence/absence of this one flag.
