req `915b20b2`). Fires the composite grounding `a49471de`: closes the current
waiting-check (→ Done) and creates the next iteration cloning it (label / zone /
parent / relates / body), status Backlog, planned for tomorrow, `prevIteration`
pointing back at the closed check.

- **Category**: creation. **Icon**: copy-plus. **CLI**: `next-waiting-check-iteration`.
