# Create Partially Done next iteration (clone)

Step 1 of the «Partially Done» composite (`d6c77239`, req `87361a62`). Creates a
new `ems__Task` cloned from the click-target ($target) — the next iteration of a
partially-closed task.

- **`targetClass`** → `ems__Task` (`1b20a8f0`); **`targetFolder`** →
  `$targetFolder` (co-located with the original, so iterations live together).
- **`labelTemplate`** → `$target.exo__Asset_label` — clones the title verbatim.
- **`cloneTargetBody: true`** — clones the original's markdown body forward
  (context notes carry across iterations; req 915b20b2 engine primitive).
- **InheritanceRules** clone the substantive task properties forward:
  `ems__Effort_area` (`9f9ede48`), `ems__Effort_parent` (`e9761329`),
  `ems__Task_zone` (`0f8c1d14`), `exo__Asset_relates` (`2b9004cf`),
  `ems__Effort_deadlineTimestamp` (`563f5c90`), `ems__Effort_timeEstimateMinutes`
  (`b0817fa9`), and set `ems__Effort_prevIteration` → the closed task
  (`6ebb59d0`).
- **PropertyDefault** sets `ems__Effort_status` = Backlog (`ce287f1a`). Fresh uid /
  createdAt / instance_class / isDefinedBy come from the Universal Default
  Template.

The next iteration deliberately carries **no** `ems__Effort_partiallyDone` flag
and **no** execution timestamps (start / end / resolution) — the IRs above only
copy substantive domain properties, and status is overridden to Backlog. Step
order in the composite is create-then-close, so the clone reads the original
while it is still pristine (Doing).
