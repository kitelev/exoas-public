# InheritanceRule: deadlineTimestamp→deadlineTimestamp (Partially Done clone)

Unconditional clone rule for the «Partially Done» create_instance grounding
(`1abb0211`, req `87361a62`). Copies the click-target's
`ems__Effort_deadlineTimestamp` (`b2a403de`) into the next iteration — the
deadline still applies to the follow-up work. Skipped when the target has no
deadline. (Distinct from execution timestamps `start`/`end`/`resolution`, which
are deliberately NOT carried forward.)
