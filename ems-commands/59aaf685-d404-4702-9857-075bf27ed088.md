# Un-archive

Homoiconic by-class command bound to `ems__Task` (binding `aab754fb`, req
`f9da9867`). Lifts an archived task out of the archive so it returns to active
views.

Fires the grounding `ec4b6e20` (`property_delete`): removes the top-level
`archived` frontmatter flag from the clicked task.

- **Precondition**: `008c6d16` — visible **only** when the target carries
  `exo__Asset_archived "true"`. Naturally hidden on every non-archived task
  (Backlog / Doing / Done without the archive flag).
- **Grounding**: `ec4b6e20` (`property_delete` of `archived`). **Category**:
  status. **Icon**: archive-restore. **CLI**: `un-archive`.
- **Inverse of** «Archive Completed» (`archiveAsset` service, sets `archived:
  true` in place, no file move). Un-archive removes that one flag — reversible,
  non-destructive. The separate cross-vault `cli archive`/`UnarchiveService`
  batch operation is unrelated to this button.
