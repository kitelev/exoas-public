# Create Task Instance (Backlog)

UI-unbound sibling of `Create Task Instance` (`bb00efed`). Creates an `ems__Task`
instance from a clicked `ems__TaskPrototype`, inheriting the prototype's
`startTime`/`endTime` (→ `plannedStart`/`plannedEnd` for the given `plannedDate`)
and writing the `exo__Asset_prototype` back-link — but starts the instance
directly in **Backlog** (grounding `98a7f3d8`), collapsing the two-step
`create-task-instance` → `move-to-backlog` into one command.

**Deliberately has no `exocmd__CommandBinding`** — it is NOT rendered as an inline
button (the atomic `create-task-instance` + `move-to-backlog` buttons already
cover the manual UI path; a bound button here would be redundant). Invoke via CLI
only: `apply create-task-instance-backlog <prototype> --input '{"label":"…","plannedDate":"YYYY-MM-DD"}' --yes`.

Used by the recurring-task planning workflow (plan regular tasks for tomorrow /
next week).
