# Create TaskPrototype instance (Backlog)

Grounding for the UI-unbound `Create Task Instance (Backlog)` command
(`73680f64`). Identical to the sibling `Create TaskPrototype instance`
(`a6ef8fda`) — same `targetClass` (`ems__Task`), `targetPrototype`
(`ems__TaskPrototype`), `inputSchema` (`label` + `plannedDate`), isDefinedBy
inheritance (`cbe000c4`), and prototype `startTime`/`endTime` → `plannedStart`/
`plannedEnd` mapping — **except** the `propertyDefault` sets the new instance's
`ems__Effort_status` to **Backlog** (`029b916d`) instead of Draft.

Used by the recurring-task planning workflow to create dated task instances
directly in Backlog in one action. Not bound to any layout (no `CommandBinding`)
— the atomic `create-task-instance` + `move-to-backlog` buttons already cover the
manual UI path; this composite-outcome command is CLI/automation-only.
