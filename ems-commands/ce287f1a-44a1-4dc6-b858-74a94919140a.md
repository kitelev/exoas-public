# PropertyDefault: ems__Effort_status = EffortStatusBacklog (Partially Done)

Declarative default-value rule for the «Partially Done» create_instance grounding
(`1abb0211`, req `87361a62`). A next iteration spawned by Partially Done starts in
**Backlog** (`753a44d5`) — the follow-up work is queued, not in progress. This
default wins over any status the clone might otherwise carry (the clone IRs do
NOT copy `ems__Effort_status`).
