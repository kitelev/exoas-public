# $tomorrow

`exocmd__SubstitutionToken` instance. Resolves at execution time to **tomorrow's**
date (today + 1 day) as `YYYY-MM-DD` (e.g. `2026-07-03`). Parameterless. Sibling of
`$today` (`665ab8ac`) — the resolver `tomorrow` is `makeDateResolver(1, "YYYY-MM-DD")`
(Веха 5 Templater `tp.date.tomorrow` parity), context-free and platform-agnostic
(plain `Date` arithmetic, no Node `fs`/`Intl`).

## Usage

Referenced from `exocmd__PropertyDefault_value` for a soft daily tickler default —
`ems__WaitingCheckTask` «Следующая итерация» stamps the next iteration's
`ems__Effort_plannedStartTimestamp` = `$tomorrow` (PropertyDefault `aac7c7cd`,
req `915b20b2`). Date-only shape matches the established `$today` plannedStart
default (`c4e16484`).
