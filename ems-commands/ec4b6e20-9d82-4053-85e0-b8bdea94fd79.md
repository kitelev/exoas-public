# Un-archive: remove the archived flag

The grounding behind the `ems__Task` «Un-archive» command (`59aaf685`, req
`f9da9867`). A `property_delete` (type `4bdf1d0b`) that removes the top-level
`archived` frontmatter key (`targetProperty: "archived"`) from the clicked task,
lifting it out of the archive so it reappears in active views.

Pure inverse of the `archiveAsset` service (which sets `archived: "true"` in
place); no engine code — `GroundingExecutor.executePropertyDelete` calls
`FrontmatterService.removeProperty(content, "archived")`.

## 2026-09-15 — ключ переведён на `exo__Asset_archived` (тикет `da0f73a3`, S7, req `960d7a3f`)

`targetProperty` теперь — TBox-объявленное свойство `exo__Asset_archived` (`exoas-exo` `79ca4e3e`). Bare `archived:` — legacy-форма: индексируется тем же триплом `exo:Asset_archived`, читается, но не пишется. Старый CLI/плагин (< релиза req `960d7a3f`) канонизирует `exo__Asset_archived` → bare `archived` (прежняя whitelist), новый держит prefixed и снимает bare при записи; `property_delete` нового ключа снимает обе формы — поэтому смена значения здесь безопасна при любом порядке обновления устройств.
