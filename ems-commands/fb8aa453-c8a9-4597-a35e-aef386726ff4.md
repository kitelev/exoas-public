# InheritanceRule: uid→prevIteration (WaitingCheckTask chain link)

Backlink rule for the `ems__WaitingCheckTask` «Следующая итерация» create_instance
grounding (`af871e36`, req `915b20b2`). Copies the click-target's `exo__Asset_uid`
(`fada7446`) into the new iteration's `ems__Effort_prevIteration` (`3104b383`) —
formatting the bare UID as `"[[<uid>]]"` — so the new check points back at the one
it supersedes (UWI child→prev). The `prevIteration` chain length is the
«how many checks it took» metric (Vision Lock 6).
