# Partially Done

Homoiconic by-class command bound to `ems__Task` (binding `04cf1c27`, req
`87361a62`). For a task you are working on (Doing) but cannot finish this pass:
marks the current task **done-but-partial** and queues a fresh next iteration.

Fires the composite grounding `d6c77239`:

1. clones the current task into a new **Backlog** `ems__Task` (label / area /
   parent / zone / relates / deadline / estimate / body carried forward),
   `ems__Effort_prevIteration` → the closed task;
2. sets the current task `ems__Effort_status` → **Done** + `endTimestamp` +
   `resolutionTimestamp`;
3. sets the current task `ems__Effort_partiallyDone` → **true**.

- **Precondition**: `577f798f` — visible only when the target is in status Doing
  AND is not a prototype (the same gate «Mark Done» uses; symbolic-IRI status
  form). Naturally hidden in Backlog / Done / Archived.
- **Grounding**: `d6c77239` (composite). **Category**: status. **Icon**: flag.
  **CLI**: `partially-done`.
- **Difference from «Create Next Iteration»** (Done-only, «finished → next cycle»)
  and «Следующая итерация» (WaitingCheckTask): Partially Done is the *failure*
  path — it closes a Doing task that fell short and marks it partial.
