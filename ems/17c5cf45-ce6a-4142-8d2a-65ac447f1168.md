# ems__ParentEffort

Marker class for efforts that were historically allowed to act as a parent in
the WBS: `ems__Project` (`7db5eeff-718a-49b0-8d2b-39b084a356e3`) and
`ems__Initiative` (`ef35dbbe-3d34-4a00-a0d1-d8dd97776463`) declare it as a
superclass.

## Since 2026-09-09 it is no longer the range of `ems__Effort_parent`

`ems__Effort_parent` (`6528ecfa-a03d-47f1-a819-9ba5fea8fc28`) was widened to
`ems__Effort` so that an `ems__Action` can nest under an `ems__Task` (founder
interview 2026-09-09; subject `0e914ac3-64bd-4e13-896a-d64b3a3e8d30`, GitHub
issue `kitelev/exocortex#4220`).

The class is **not** deprecated — that decision was never taken. It stays as the
Project/Initiative marker and as a superclass in their hierarchies; it simply
stopped being a property range.
