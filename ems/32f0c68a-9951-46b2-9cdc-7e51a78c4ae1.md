# ems__EffortTrashNote

Текст причины, по которой эффорт выброшен в корзину, — словами человека. Создаётся командой `trash` (шаг «Create trash reason», req `088f94c6`) и ссылается на выброшенный эффорт через `exo__Asset_relates` (новое → старое).

Отличие от `ems__EffortTrashReason`: тот класс — закрытый набор из двух категорий («Неактуально / осознанный отказ», «Начато, не закончено»), значение свойства `ems__Effort_trashedReason`. Свободный текст живёт в отдельном классе, чтобы не попадать в список категорий: поле перечисляет все экземпляры класса из своего `range` вместе с подклассами, поэтому этот класс намеренно НЕ подкласс `ems__EffortTrashReason`.

Найти причины выброшенной задачи:

```sparql
PREFIX exo: <https://exocortex.my/ontology/exo#>
SELECT ?note ?text WHERE {
  ?note exo:Instance_class ?c . FILTER(CONTAINS(STR(?c), 'EffortTrashNote'))
  ?note exo:Asset_relates ?effort .
  ?note exo:Asset_label ?text .
}
```
