# Project Default Workflow — ← Backlog

Transition `Doing` → `Backlog` (rollback). Clears `ems__Effort_startTimestamp` via
postActions `[Delete start timestamp]` — symmetric with the Task workflow, and with
this workflow's own `▶ Start`, which SETS that timestamp through the same grounding.

⛤ Until 2026-08-19 this transition carried no `postActions`, so `apply
rollback-to-backlog` on an `ems__Project` reported "start timestamp cleared" and left
the field in place (bug `8f35fec0`). The body also read `Analysis → Backlog`, which
never matched `ems__WorkflowTransition_from` (= `Doing`).
