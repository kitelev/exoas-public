# ems__Reminder_afterEffort

Задача, по завершении которой приходит напоминание («когда закончу — напомни»). Напоминание с этим свойством ставится БЕЗ `ems__Reminder_at`: время срабатывания неизвестно заранее. Исполнитель — reminder-checker: на каждом опросе он смотрит, закрыта ли задача, и в момент закрытия записывает `ems__Reminder_at` = сейчас; дальше это обычное напоминание (отправка, отметка «отправлено», отсрочка кнопкой, «✅ Готово»).

«Закрыта» — статус Done или Trashed либо стоит `ems__Effort_endTimestamp` (тот же смысл, что у `ems__Effort_blocker`). Статус судится по UID ссылки, а не по подписи после `|`.

Пример: «когда закончу тренировку, напомни выпить воды» — напоминание с текстом «выпить воды», без `ems__Reminder_at`, где это свойство ссылается на текущую задачу «тренировка» (значение — вики-ссылка на её UID).

Ограничения:

- задачу закрыли на другом устройстве — хранилище бота узнает об этом при следующей синхронизации;
- если у напоминания уже есть `ems__Reminder_at`, срабатывает оно по времени, а это свойство не используется;
- включается для бота отдельно (`REMIND_AFTER_BOTS` у reminder-checker); вне гейта такое напоминание не отправляется, и это записывается в журнал демона.

Отменить ждущее напоминание — записать `ems__Reminder_doneAt`.
