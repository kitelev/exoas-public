# ems__WorkflowTransition

Разрешённый переход между двумя статусами внутри `ems__Workflow` — элемент машины состояний, а не событие: описывает, ЧТО дозволено, а не что произошло.

Несущие свойства (по `docs/how-to/WORKFLOW_CUSTOMIZATION.md`): `_workflow` · `_from` · `_to` · `_label` (подпись кнопки) · `_icon` · `_isRollback`.

Замер 2026-09-20: **15 инстансов**, все — переходы дефолтных workflow (`Task Default Workflow — ← Backlog`, `Project Default Workflow — ▶ Start`).
