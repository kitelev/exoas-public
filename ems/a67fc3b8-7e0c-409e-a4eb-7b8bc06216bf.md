# ems__WaitingCheckTaskPrototype

Прототип-класс для узлов-ожидания в WBS-прототипах (напр. «{{сотрудник}} заполнил цели» в прототипе ревьюшницы). Инстанцируется в `ems__WaitingCheckTask` (`47dac51c`), а не в `ems__Task` — чтобы инстанс получил GTD «Waiting For» lifecycle (кнопка «Следующая итерация», `ems__Effort_prevIteration`-цепочка).

superClass:
- `ems__TaskPrototype` (`df7e579d`) → транзитивно `ems__EffortPrototype` (участвует в `ems__EffortPrototype_parentEffortPrototype`-иерархии прототипов) + `ems__Task` + `exo__Prototype`.
- `ems__WaitingCheckTask` (`47dac51c`) → семантика цели инстанцирования.

Issue kitelev/exocortex#3881 (Gap 2). Разворачивание субграфа прототипа выводит целевой класс инстанса из non-Prototype superClass узла-прототипа: `ems__WaitingCheckTaskPrototype` → `ems__WaitingCheckTask`.
