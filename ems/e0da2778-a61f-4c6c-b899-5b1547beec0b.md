# ems__Effort_partiallyDone

Boolean marker (`exo__BooleanProperty`, domain `ems__Effort`) set on a task that
was closed **partially** — the work could not be finished in this pass, so the
effort is marked Done but a fresh next iteration is spawned (req
`87361a62-76a3-4ba9-b008-432838743800`, «Partially Done» command).

`true` = «finished short, a second attempt exists» (the next iteration links back
via `ems__Effort_prevIteration`). Absent / `false` = a normal (fully) done effort.
Set by the «Partially Done» composite grounding; a spawned next iteration never
inherits this flag.

## Usage

```sparql
SELECT ?t WHERE {
  ?t exo:Instance_class ems:Task .
  ?t ems:Effort_partiallyDone true .
}
```
