# ems__EffortPrototype_anchorDelayMinutes

Задержка после события-якоря, в минутах: экземпляр прототипа с `ems__EffortPrototype_anchorPrototype` назначается на момент события плюс эта задержка. Без `ems__EffortPrototype_anchorPrototype` свойство ничего не значит.

Значение — целое число минут от 0 до 720 без кавычек. Нет свойства — 0 (сразу при событии). Не число, отрицательное или больше 720 — тоже 0.

Пример: 15 — напоминание о Зодаке через 15 минут после «Проснулся».

Ограничения:

- задержка не прибавляется к запасной минуте `ems__EffortPrototype_anchorLatestTime`: итоговая минута — меньшее из «событие + задержка» и запасной;
- поменять задержку можно в любой момент; на сегодняшнюю дозу правка действует, только пока по ней не отправлено ни одного напоминания.
