**ExoSync** — механизм синхронизации канонных vault (git-free) с remote через **GitHub REST API**, а не git. Оперирует всеми materialized AssetSpace устройства.

## Зачем
Канонные vault (vault-my / vault-tbank / vault-exodev) — tarball-mount, БЕЗ собственного `.git` → обычный `git push` невозможен. ExoSync пушит через REST (orphan-commit, `force:false` = неразрушающий).

## Операции
- **`exosync-parity`** — read-only divergence check ДО мутации (показывает, у каких репо есть raw-diffs).
- **`exosync sync`** — полный `pull → merge → push` цикл (ставит watermark).
- **`exosync push`** — только push локальной дельты (без pull/merge, ниже surface).

## Механика
- Cross-repo move файла = **delete(source) + add(target)** в ОДНОМ раунде.
- Discovery ассетспейсов — по скану папок + registry-дескриптор (`exo__AssetSpace_source`), **НЕ** по `.gitmodules`.
- Auth: `--token-from-gh` резолвит PAT через `gh auth token` (без утечки в history/ps).

## Nuance
Push аддитивен → `pushed 0` для уже-синканых файлов (фоновый auto-sync launchd мог опередить). Verify отгрузку через `gh api .../contents?ref=main`, а не по счётчику `pushed`.
