# Introspect: instance count of a class (`$className`)

Parametrized read-side introspection query (`query__NamedQuery`) backing `describe-class <class>` / `classes <class>` (req `2678df55`). Counts the instances of any class whose IRI contains the `$className` literal parameter. The `$className` token is substituted by `NamedQueryRunner` as an escaped SPARQL string literal (engine-controlled substitution, read-only) before the query is parsed.

```sparql
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
SELECT (COUNT(?instance) AS ?count)
WHERE {
  ?instance rdf:type ?class .
  FILTER(CONTAINS(STR(?class), $className))
}
```
