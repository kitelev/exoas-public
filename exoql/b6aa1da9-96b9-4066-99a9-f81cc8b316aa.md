# Introspect: classes with instance counts

Read-side introspection query (`query__NamedQuery`) backing the CLI `classes` command (req `2678df55`). Lists every RDF class in the vault with the number of its instances, most-populated first. The `classes` command resolves this asset by UID, executes the body read-only through `NamedQueryRunner`, and renders the rows with the in-code ASCII-table formatter (`prefix__local` truncation). Editing this SPARQL body changes what `classes` prints — with no code change.

```sparql
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
SELECT ?class (COUNT(?instance) AS ?count)
WHERE {
  ?instance rdf:type ?class .
}
GROUP BY ?class
ORDER BY DESC(?count)
```
