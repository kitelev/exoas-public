# NessyLog: частота по типу ошибки (`$errorType`)

Параметризованный read-side запрос (`query__NamedQuery`) для подсчёта числа `NessyLog`-записей заданного типа ошибки из несинхр. ассетспейса `exoas-nessy-logs`. `$errorType` подставляется `NamedQueryRunner` как escaped SPARQL string literal (например `AutoModeClassifier`, `SigKill`, `Validation`, `TargetNotFound`, `ExitCode`). Пример использования — отслеживание частоты блокировок auto-mode classifier из графа.

```sparql
PREFIX exo: <https://exocortex.my/ontology/exo#>
PREFIX nl: <https://exocortex.my/ontology/nessy-log#>
SELECT (COUNT(?a) AS ?count) WHERE {
  ?a a nl:NessyLog .
  ?a nl:NessyLog_errorType ?t .
  ?t exo:Asset_label $errorType .
}
```
