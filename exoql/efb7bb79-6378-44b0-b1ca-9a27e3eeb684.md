# Introspect: properties used by a class (`$className`)

Parametrized read-side introspection query (`query__NamedQuery`) backing `describe-class <class>` / `classes <class>` (req `2678df55`). Returns each predicate used by instances of any class whose IRI contains the `$className` literal parameter, with the usage count, most-used first (excluding `rdf:type` itself). The `$className` token is substituted by `NamedQueryRunner` as an escaped SPARQL string literal (engine-controlled substitution, read-only) before parse.

```sparql
PREFIX rdf: <http://www.w3.org/1999/02/22-rdf-syntax-ns#>
SELECT ?property (COUNT(?value) AS ?usageCount)
WHERE {
  ?instance rdf:type ?class .
  ?instance ?property ?value .
  FILTER(CONTAINS(STR(?class), $className))
  FILTER(?property != rdf:type)
}
GROUP BY ?property
ORDER BY DESC(?usageCount)
```
