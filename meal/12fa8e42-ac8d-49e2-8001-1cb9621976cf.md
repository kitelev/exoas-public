# meal__DishServing_meal

Приём пищи, в рамках которого блюдо было съедено.

- **Domain:** `meal__DishServing`
- **Range:** `ems__Effort` (ObjectProperty)
- **Cardinality:** 0..1 — опционально

## Почему range = ems__Effort, а не ems__Task

Приём пищи сегодня — инстанс `ems__Task`, но `ems__Effort` общее и не сломается,
если завтра meal станет другим подклассом Effort.

## ⛤ Конвенция «один источник даты»

Если `_meal` заполнен — дата подачи берётся из `ems__Effort_startTimestamp`
приёма пищи, а собственный `exo__Event_timestamp` (унаследованный от
`exo__Event`) **не заполняется**. Собственный timestamp — только для
standalone-подач без эффорта.

Механически это не энфорсится (SHACL-lite не выражает «ровно одно из двух»).
Машинная проверка инварианта:

```sparql
PREFIX exo:  <https://exocortex.my/ontology/exo#>
PREFIX meal: <https://exocortex.my/ontology/meal#>
SELECT ?s WHERE { ?s meal:DishServing_meal ?m . ?s exo:Event_timestamp ?t }
```

Обязан возвращать **0 строк**. Иначе двойной источник даты даст fan-out
в запросах с несколькими OPTIONAL.
