# meal__DishServing_dish

Тип блюда, которое было съедено.

- **Domain:** `meal__DishServing`
- **Range:** `concept__Concept` (ObjectProperty)
- **Cardinality:** 1..1 — обязательно

## Зачем обязательно

Это ключ соединения между подачами в разных заведениях. Без него неотвечаем
вопрос «в каком заведении самый вкусный ‹блюдо X›» — то есть класс не выполняет
своё назначение. Цена: на каждую новую позицию меню заводится концепт;
скилл `/meal-log` создаёт недостающий автоматически.

## Инварианты

- ⛔ Значение — **только UID-форма** wikilink `[[<uid>]]` (strip-canon).
  Label-форма (`[[Наполеон]]`) остаётся нерезолвленным литералом, движок
  печатает `literal-safety guard fired`, и запросы **молча** возвращают 0 строк.
- Концепт-блюдо должен иметь `concept__Concept_genus` → пищевой genus.
  Формально `_dish` принимает любой `concept__Concept` (SHACL-lite не выражает
  property-path констрейнт) — инвариант энфорсится скиллом `/meal-log`.
