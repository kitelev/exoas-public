# meal__DishServing_rating

Субъективная оценка блюда.

- **Domain:** `meal__DishServing`
- **Range:** **xsd:decimal, шкала 0..10** (DatatypeProperty)
- **Cardinality:** 0..1 — опционально

## Дробные значения обязательны к поддержке

Нотация владельца — `N/10`, и она **включает дробные**: реальные оценки
`6/10`, `6.5/10`, `8/10`, `9/10`. Значение пишется во frontmatter
**незакавыченным числом** — тогда оно эмитится как `xsd:decimal`
и сравнивается численно.

Эмпирически проверено 2026-07-31:
`SELECT ?r WHERE { VALUES ?r { 4 6 6.5 9 10 } } ORDER BY DESC(?r)`
→ **10, 9, 6.5, 6, 4** — численная сортировка, не лексикографическая
(строковая поставила бы `9` перед `10`). `FILTER(?r >= 8)` → `9, 10`.

⛤ Строгое равенство сравнивать через `STR(?r)`; порядок и неравенства —
напрямую по числу.

## Инвариант

⛔ **Отсутствие оценки ≠ 0.** Если оценка не была дана — свойство просто
отсутствует. Не подставлять значение по умолчанию, не выводить оценку из
текстового впечатления («вкусный» ≠ 8). Впечатления — в тело подачи.
