# Set End Timestamp

Dynamic command that sets `ems__Effort_endTimestamp` — the ACTUAL end — to a user-provided datetime. For digitizing an effort **post-factum** (backdate the real end). CLI/palette command, no inline button — mirrors `Set Planned Start` (6bc86da6), targeting the end fact timestamp.

- **Grounding**: `Set end timestamp` (e3df4a3d) → `updateProperty` on `ems__Effort_endTimestamp`
- **Input**: `{"value":"<ISO datetime>"}`
- Issue #3970 (composable from the existing `updateProperty` service — vault-data, no engine code).
