# Set start timestamp

Grounding action that calls the `updateProperty` service to set `ems__Effort_startTimestamp` — the ACTUAL start timestamp — to a user-provided datetime value.

Uses `service_call` grounding type with `updateProperty` service. Mirrors `Set planned start timestamp` (85687461) but targets the fact timestamp instead of the planned one, so an effort digitized post-factum can record its real start. Issue #3970.
