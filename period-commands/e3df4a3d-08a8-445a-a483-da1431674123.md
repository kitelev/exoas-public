# Set end timestamp

Grounding action that calls the `updateProperty` service to set `ems__Effort_endTimestamp` — the ACTUAL end timestamp — to a user-provided datetime value.

Uses `service_call` grounding type with `updateProperty` service. Mirrors `Set planned end timestamp` but targets the fact timestamp, so an effort digitized post-factum can record its real end. Issue #3970.
